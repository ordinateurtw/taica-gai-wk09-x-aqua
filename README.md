# X-Aqua｜智慧水產養殖知識網站

TAICA 115-1 生成式 AI 課程 WK09 專案。

本專案使用 Codex CLI，依照 `AGENTS.md` 規則建立可持續擴充的智慧水產養殖知識網站。

## 目前功能

- 水質管理知識
- 白蝦健康與風險
- 白蝦飼料與投餵管理
- Phase 01 水質資料管理原型

## 四階段開發規劃

1. Phase 01：人工輸入水溫、pH、DO、鹽度。
2. Phase 02：逐步整合四項 AIoT 感測數據。
3. Phase 03：全天候水質監控。
4. Phase 04：Dashboard UI、DaaS 與資安。

## AI 開發規範

所有新增或修改工作，必須先閱讀 `AGENTS.md`。

## Deployment

GitHub Pages 發布來源：`main` 分支、`/(root)`。

Deployment validation: WK09 X-Aqua

## 注意事項

目前 Phase 01 為本機瀏覽器資料管理原型，不代表正式雲端資料庫、即時 API 或 AIoT 系統已上線。
